# 決定の多様性を体験するアプリ

リキッド・デモクラシー（Liquid Democracy）のシミュレーター

## 概要

このアプリは、チームの意思決定における**リキッド・デモクラシー**の仕組みを体験できるシミュレーターです。

### リキッド・デモクラシーとは？

- **直接投票**：自分で直接、賛成/反対/中立を投票できる
- **委任投票**：信頼する人に投票権を委任できる
- **柔軟性**：トピックごとに投票方法を変更可能

専門知識を持つ人に委任することで、より良い意思決定が可能になります。

## 主な機能

### 管理画面
- 人物管理：名前と専門分野タグを登録
- トピック管理：決定事項を登録
- 投票マトリクス：人物×トピックで投票/委任を設定

### 結果画面
- 集計結果：賛成/反対/中立/循環/未解決の票数を表示
- 棒グラフ：視覚的な投票分布
- 委任ネットワーク図：委任関係を可視化
- 個人別詳細：各人の投票方法、最終結果、委任チェーンを表示

### コア機能
- ✅ 委任チェーン解決アルゴリズム
- ✅ 循環委任検出
- ✅ 多段委任サポート
- ✅ テスト駆動開発（8/8テスト合格）

## 技術スタック

- **フレームワーク**: React 19 + TypeScript
- **ビルドツール**: Vite 8
- **ルーティング**: React Router 7
- **ステート管理**: Context API + useReducer
- **テスト**: Vitest + jsdom

## セットアップ

```bash

# 開発サーバー起動

# テスト実行
npm test

# ビルド
npm run build
```

## サンプルシナリオ

アプリには3つのサンプルシナリオが含まれています：

1. **新機能Aの実装**（技術的決定）
   - 技術専門家に委任が集中
   - 多段委任のデモ

2. **価格改定の提案**（ビジネス判断）
   - ビジネス専門家への委任

3. **リモートワーク継続**（循環委任のデモ）
   - 循環委任の検出と表示
